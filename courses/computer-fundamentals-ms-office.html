Computer Fundamentals & MS Office Foundation

A structured beginner programme covering computer concepts, Windows use, file management, internet and email, followed by practical office application skills.

What you will learn

  • Identify common computer components and their functions
  • Use Windows and organise files confidently
  • Use the internet and email for basic tasks
  • Create documents, spreadsheets and presentations

Module-wise syllabus

Computer fundamentals

  • Computer components and input/output devices
  • Operating system and Windows basics
  • Desktop, folders, files and storage

Internet and communication

  • Web browsing and safe search habits
  • Email composition, attachments and etiquette
  • Basic digital safety and responsible use

Office applications

  • Word document preparation
  • Excel formulas, functions and charts
  • PowerPoint slide creation and practical assessment

Practical activities & assessment

Guided explanation, hands-on practice and review. Activities are adjusted to the learner’s starting level and batch pace.

  • File and folder organisation task
  • Word, Excel and PowerPoint exercises
  • Integrated final practical task

Eligibility & learning approach

No prior computer knowledge is required.

Training is delivered through guided sessions with opportunities to practise, ask questions and review completed work. The batch calendar is shared during admission counselling.
