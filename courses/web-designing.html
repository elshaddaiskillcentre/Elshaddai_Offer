Web Designing Foundation – HTML, CSS & JavaScript

A practical front-end web design programme. Learners create page structures with HTML, style layouts with CSS and add basic interactions using JavaScript.

Course Information

Duration30 guided sessions
Course fee₹8,500
Fee basisFixed course fee
Suitable forStudents, college learners and beginners
Batch dates, session timing and seat availability are confirmed before enrolment. For tuition and research support, charges are based on the hourly sessions taken.

What you will learn

  • Build structured web pages using semantic HTML
  • Style layouts using CSS and responsive techniques
  • Add basic interactivity using JavaScript
  • Create and present a multi-page website project

Module-wise syllabus

HTML foundations

  • Web page structure and semantic elements
  • Headings, links, images, lists and tables
  • Forms and accessible markup basics

CSS and responsive design

  • Selectors, typography, colours and spacing
  • Box model, flexbox and grid basics
  • Responsive layouts for mobile and desktop

JavaScript essentials

  • Variables, data types and operators
  • Conditions, loops and functions
  • DOM selection, events and form validation

Website project

  • Page planning and navigation
  • Responsive multi-page website
  • Testing, refinement and project presentation

Practical activities & assessment

Guided explanation, hands-on practice and review. Activities are adjusted to the learner’s starting level and batch pace.

  • Personal profile page
  • Responsive landing page
  • A complete multi-page website

Eligibility & learning approach

Basic computer skills and file management are helpful. No previous web development experience is required.

Training is delivered through guided sessions with opportunities to practise, ask questions and review completed work. The batch calendar is shared during admission counselling.
